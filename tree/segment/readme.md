# 线段树：叶子更新、父节点合并与区间分解

现有实现：[307. 区域和检索－数组可修改](https://leetcode.com/problems/range-sum-query-mutable/)，代码见 [307_1.go](307_1.go)。

## 不变量与固定骨架

每个内部节点保存左右孩子区间的合并结果，求和时为 `tree[p]=tree[2*p]+tree[2*p+1]`。

```text
构建：把数组放到叶子，从最后一个父节点向根合并
单点赋值：修改叶子，沿祖先路径重新合并
区间查询：把 [left,right) 分解为若干互不重叠的节点，合并结果
```

查询时若 left 为右孩子，取它后令 left++；若 right 为右孩子，先 --right 再取它；之后两边都除以 2。这样每层只取当前边界无法共同上移的区间。

本题公开方法 `SumRange(left,right)` 接收闭区间，内部通过 `right+1` 转为半开区间。初始化 O(n)，单点更新和查询 O(log n)，空间 O(n)。

变为最小值、最大值等聚合时，同时替换合并运算与单位元。区间修改需要额外维护懒标记规则，不能直接复用单点赋值操作。静态求和与批量区间加法分别见 [前缀状态与差分](../../prefix_sum/readme.md)。

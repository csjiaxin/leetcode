# 跳跃题族：根据边与目标选择算法

这个历史题族继续保留在 dp 下作为算法对照索引。题名都包含“跳跃”，不意味着都使用动态规划，也不意味着共用一个移动指针或一个递推公式。

## 1. 最远可达位置与贪心分层

| 实现 | 目标 | 不变量 |
| --- | --- | --- |
| [55](../l55/55.go) | 能否到达最后位置 | 扫描位置不超过当前最远可达范围 |
| [45](../l45/45.go) | 最少跳数 | 当前层边界内的节点都能用相同步数到达，维护下一层最远边界 |

55 的建模骨架：

~~~text
farthest = 0
依次扫描 i:
    若 i>farthest，则无法到达
    farthest = max(farthest, i+nums[i])
~~~

45 把可达区间当作 BFS 层，在到达当前层边界时增加一步。原题保证可达；推广到不保证可达的输入时，必须检测边界无法推进。不能简单解释成“每次直接落在最远下标”。

## 2. 无权图上的 BFS

~~~text
起点入队并标记访问
依次出队:
    若满足目标，返回当前距离
    枚举合法邻居
    对未访问邻居：入队时标记，并设置距离
~~~

- [1306](../l1306/1306.go)：邻居为 i±arr[i]；目标是数值为 0 的位置，不是数组末尾。
- [1345](../l1345/1345.go)：邻居是相邻下标及所有同值下标。按值分组后，每个同值列表只展开一次，避免反复扫描退化。

BFS 的状态是当前位置，访问记录用于防止环；最短距离依赖每步代价相同。两题不能套 55 的最远边界，因为可达集合的结构和方向不同。

## 3. 依赖无环时的记忆化 DP

~~~text
best(i):
    若已缓存，返回
    result = 1
    分别扫描左右距离 1..d:
        遇到高度 >= arr[i] 时，停止该方向
        result = max(result, 1+best(j))
    缓存 result
~~~

答案是在所有起点中取最大访问位置数，包含起点。扫描方向中的高柱会挡住更远位置，不能只检查落点高度。

## 4. 如何复用

- 先定义图的边，再确定目标是可达性、最少步数还是最大收益。
- 若压缩成最远边界，证明被省略的位置不影响答案。
- 若使用 BFS，保存完整状态并在入队时去重。
- 若递归求最优值，先证明依赖无环；普通 memo 不能自动处理有环最长路。

## 1. 相邻选择：前一位置选或不选

处理当前元素前，skip/take 分别是前缀末项不选/选的最优值。更新时所有右侧都必须读取旧状态。

~~~go
func BestIndependent(nums []int) int {
    skip, take := 0, 0
    for _, x := range nums {
        skip, take = max(skip, take), skip+x
    }
    return max(skip, take)
}
~~~

适用于允许全部不选、相邻元素不能同时选择的线性收益问题。空前缀收益为 0；环形问题需要分别排除首项或尾项，单元素单独处理。

## 2. 以 i 结尾的最优序列

~~~go
func LISLength(nums []int) int {
    dp := make([]int, len(nums))
    answer := 0
    for i := range nums {
        dp[i] = 1
        for j := 0; j < i; j++ {
            if nums[j] < nums[i] {
                dp[i] = max(dp[i], dp[j]+1)
            }
        }
        answer = max(answer, dp[i])
    }
    return answer
}
~~~

不变量：计算 dp[i] 时，所有 j<i 的结尾状态已经完成。复杂度 O(n²)，空间 O(n)。O(n log n) 的 tails 方法重新设计了状态，不能只把上面的内循环替换为普通查找。

当转移能拆成只依赖旧下标的项和只依赖当前下标的项，可以维护前缀最优值：

~~~text
for 当前右端点 j:
    candidate = 历史前驱最优值 + 当前项
    更新答案
    将 j 纳入历史前驱集合
~~~

    处理终态

    按目标合并：计数相加 / 代价取小 / 收益取大

~~~

# 区间 DP：由短区间构造长区间

原 Interval 与 merge_interval 已合并。相同题号的不同写法保留在 legacy 或 variants 中，不把同名函数和测试直接拼进一个 Go 包。

## 1. 闭区间填表骨架

令 dp[l][r] 只描述连续区间 [l,r]。每次转移依赖更短的区间，因此按长度递增：

~~~go
func IntervalTable[T any](../
    n int,
    base func(i int) T,
    step func(l, r int, dp [][]T) T,
) [][]T {
    dp := make([][]T, n)
    for i := range dp {
        dp[i] = make([]T, n)
        dp[i][i] = base(i)
    }
    for length := 2; length <= n; length++ {
        for l := 0; l+length <= n; l++ {
            r := l + length - 1
            dp[l][r] = step(l, r, dp)
        }
    }
    return dp
}
~~~

这是文档骨架，未自动改写旧实现。step 只能读取已经完成的短区间；空区间、不可达状态和答案提取需由题目决定。最小值问题不能默认把未计算格子的零值当作合法最优值。

当每格枚举全部分割点时，时间通常 O(n³)，表格空间 O(n²)。只有两端转移的题常为 O(n²)。

## 2. 三种不同的区间转移

### 两端关系

~~~text
两端匹配：从内层区间转移
两端不匹配：尝试去掉左端或右端，再按目标合并
~~~

- [5：回文子串](../../strings/l5/5.go)：布尔状态，要求连续；相邻字符需要处理空内层。
- [516：回文子序列](../../strings/l516/516.go)：最大长度，允许跳过字符。
- [1312：最少插入](../../strings/l1312/1312.go)：最少操作数，不是最长长度。

这些原有字符串实现保留原址，避免破坏字符串系列结构；本页交叉索引其区间状态。

### 枚举分割点

~~~text
dp[l][r] = 在合法 k 中选最优的
           dp[l][k] + dp[k+1][r] + mergeCost(l,k,r)
~~~

- [1547](../l1547/1547.go)：固定切点坐标后，枚举第一次切割；新增费用是当前棍段长度。
- [1130 历史实现](../l1130/1130)：合并左右树，附加两侧叶子最大值的乘积。
- [96 历史实现](../l96/96)：枚举根，左右方案数相乘，再对不同根相加。它是计数，不是取 min。
- [1039 历史实现](../l1039/1039.go)：保留原三角剖分写法。历史代码存在不代表每个边界已获得新验证。

### 枚举最后操作，固定外边界

[312](../l312/312.go) 的关键是选最后戳破的气球。左右外边界仍存在，子区间才能独立计算：

~~~text
在两侧补边界后，dp[l][r] 表示开区间 (l,r)
dp[l][r] = max(dp[l][k] + dp[k][r] + a[l]*a[k]*a[r])
其中 l<k<r
~~~

它使用开区间，不能不改下标直接代入前面的闭区间骨架。[递归片段](../l312/legacy/recursive/312)与[旧迭代片段](../l312/legacy/iterative/312_dp)均保留。

## 3. 额外状态与不同合并规则

| 题目 | 不可省略的信息 |

| [1000](../l1000/1000.go) | 还需表示合并成多少堆，或证明该信息能由长度余数推出 |
| [1000 旧三维片段](../l1000/legacy/1000) | 显式保存区间与堆数，保留不同方法 |

1000 先检查 (n-1) 是否能被 K-1 整除。二维矩阵不是“状态天然二维”的保证，也不能把区间长度一维当成额外独立选择。

## 常见错误

- 没有统一开区间/闭区间约定。
- 把“第一次切割”与“最后一次戳破”混用，导致子问题边界不独立。
- 最小值状态误用 0 初始化，或从不可达值继续相加。
- 博弈中把对手的最优分差当作自己的收益直接相加。

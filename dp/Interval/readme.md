# 区间动态规划

各题目录包含 Go 解法和测试，中文题解统一收录在本文。通常按区间长度从小到大计算，先得到短区间，再组合为长区间。

| 题目 | 难度 | 核心决策 | 时间 | 空间 |
| --- | --- | --- | --- | --- |
| [1690. 石子游戏 VII](#lc1690) | 中等 | 两端博弈 + 前缀和，得分是移除后剩余区间和 | O(n²) | O(n²) |
| [375. 猜数字大小 II](#lc375) | 中等 | 枚举猜测，对左右取最坏，再选最低预算 | O(n³) | O(n²) |
| [1547. 切棍子的最小成本](#lc1547) | 困难 | 枚举当前区间第一刀，之后两段独立 | O(m³) | O(m²) |
| [312. 戳气球](#lc312) | 困难 | 枚举最后戳破的气球，保留左右边界 | O(n³) | O(n²) |
| [664. 奇怪的打印机](#lc664) | 困难 | 相同字符共享打印操作，允许覆盖 | O(n³) | O(n²) |
| [1000. 合并石头的最低成本](#lc1000) | 困难 | 模约束决定剩余堆数，限制分割点步长 | O(n³) 最坏 | O(n²) |

1547 的 m 是切点数加两个端点；其他题目的 n 是原始输入规模。1000 更精确的时间界见题目说明。

## 如何识别转移

- 两端行动：从 `[i+1,j]`、`[i,j-1]` 转移，例如 1690。
- 第一刀：固定第一次决策后两边独立，例如 1547、375。
- 最后一步：倒过来枚举，保持邻居不变，例如 312。
- 合并操作：相同字符共享一次打印，例如 664。
- 额外约束：堆数可作为第三维，或利用模关系压缩，例如 1000。

注意闭区间与开区间的区别：312、1547 的边界不参与当前子问题；1690、664、1000 的两端属于当前区间。

从仓库根目录运行全部测试：

```sh
go test ./dp/interval/... -count=1 -cover
```

测试失败信息包含 `t.Name()`，便于定位具体用例。原有 `dp/stone`、`dp/merge_interval` 等目录未移动或修改。

## 1690. 石子游戏 VII

[题目](https://leetcode.com/problems/stone-game-vii/) · 中等 · [Go 解法](l1690/1690.go)

### 思路：两端博弈 + 前缀和

每回合移除左端或右端，获得的是**移除后剩余区间的总和**，不是被移除石子的值。Alice 最大化最终分差，Bob 最小化分差；换到当前玩家视角，就是每个人都最大化自己的相对分差。

定义 `dp[i][j]` 为只剩闭区间 `[i,j]`、双方最优行动时，当前玩家减去对手的最大后续得分差。角色随回合交换，因此需要减去子问题的分差，而不是相加。

令 `prefix[t]` 为前 t 个石子的总和：

```text
移除左端：prefix[j+1] - prefix[i+1] - dp[i+1][j]
移除右端：prefix[j]   - prefix[i]   - dp[i][j-1]
dp[i][j] = max(上述两项)
```

### 边界与遍历

`dp[i][i] = 0`：移除最后一颗石子后没有剩余石子，得到零分。按区间长度从 2 到 n 填表，答案为 `dp[0][n-1]`。

### 正确性

每个合法行动必为移除左端或右端。固定行动后，本次收益已确定；剩余局面由对手先手，其最优分差在当前玩家视角下取负。枚举两种行动并取最大即涵盖全部最优策略。由短区间归纳，整个表正确。

### 示例

`[5,3,1,4,2]`：移除左端的候选为 `10 - dp[1][4] = 10-7=3`，移除右端为 `13 - dp[0][3] = 13-7=6`，答案为 6。

### 复杂度

时间 O(n²)，空间 O(n²)，前缀和让每次区间求和为 O(1)。

```sh
go test ./dp/interval/l1690 -v
```

## 375. 猜数字大小 II

[题目](https://leetcode.com/problems/guess-number-higher-or-lower-ii/) · 中等 · [Go 解法](l375/375.go)

### 思路：最坏情况下的最优策略

只有**猜错**才支付猜测数字的金额。目标不是平均开销最小，而是无论答案为何都保证猜中所需的最低预算。普通二分缩小猜测次数，但没有考虑数字本身的价格。

定义 `dp[i][j]` 为答案在闭区间 `[i,j]` 内时，保证获胜的最少预算。枚举第一次猜测 `g`：

```text
cost(g) = g + max(dp[i][g-1], dp[g+1][j])
dp[i][j] = min(cost(g))，i <= g <= j
```

内层 max 表示猜错后必须应对更贵的一侧；外层 min 表示我们主动选择最好的猜测。猜中分支成本是 0，不影响长度至少为 2 的区间的最坏情况。

### 边界与遍历

空区间和单数字区间费用都是 0：唯一数字直接猜中，不收费。表分配为 `(n+2) × (n+2)`，方便表示空的左右区间。按长度从 2 到 n 填表，返回 `dp[1][n]`。

### 正确性

任意策略都有第一次猜测 g；猜错后左右分支必须分别具有足够的保证预算，所以该策略至少需要 `cost(g)`。反过来，按最优子策略继续猜测恰好能达到该预算。枚举所有 g 并取最小，因此得到最优保证预算。

### 示例

`n=3`：猜 2，错误时付 2，然后只剩 1 或 3，可免费猜中。预算为 2。若先猜 1，最坏情况预算为 `1+2=3`。

`n=10` 的答案为 16，而不是所有猜测数字的总和。

### 复杂度

O(n²) 个区间，每个枚举 O(n) 个猜测，时间 O(n³)，空间 O(n²)。

```sh
go test ./dp/interval/l375 -v
```

## 1547. 切棍子的最小成本

[题目](https://leetcode.com/problems/minimum-cost-to-cut-a-stick/) · 困难 · [Go 解法](l1547/1547.go)

### 思路：枚举当前区间的第一刀

每次切割费用是**被切的那一段木棍的完整长度**，不是切点坐标。第一刀决定两段独立子问题。复制 cuts，加上边界 0、n 并排序，得到 points；不修改调用者的 cuts。

定义 `dp[i][j]` 为将边界 `points[i]` 与 `points[j]` 之间的所有要求切点切完的最小成本。两端仅表示边界，不作为待切位置。

```text
dp[i][j] = min(dp[i][k] + dp[k][j] + points[j] - points[i])
           i < k < j
```

k 是这段木棍的**第一刀**。切开后左右物理上分离，各自独立求最优。不要将这里与戳气球的“最后一个”混淆。

### 边界与遍历

相邻边界之间没有待切点，`dp[i][i+1]=0`。按索引间距 gap 从 2 递增填表，返回 `dp[0][m-1]`，其中 `m=len(cuts)+2`。DP 按切点个数建表，不按可能达到一百万的木棍长度建表。

### 正确性

任意合法切割顺序都有第一刀 k，其成本必为当前段长。此后两段互不影响，各自必须至少付出对应的最优子问题费用。枚举所有第一刀取最小既是下界，也是可执行策略的成本，故转移正确。

### 示例

`n=7, cuts=[1,3,4,5]`：先切 3，费用 7；左段切 1，费用 3；右段先切 5，费用 4，再切 4，费用 2。总计 `7+3+4+2=16`。

### 复杂度

排序 O(m log m)，DP 时间 O(m³)，总空间 O(m²)。

```sh
go test ./dp/interval/l1547 -v
```

## 312. 戳气球

[题目](https://leetcode.com/problems/burst-balloons/) · 困难 · [Go 解法](l312/312.go)

### 思路：枚举区间中最后戳破的气球

若枚举第一个戳破的气球，两边的邻居之后会改变，子问题难以独立。反过来固定最后戳破的 k，则 k 被戳破前，左右子区间已经清空，邻居正好是固定的两端。

在 nums 两端加值为 1 的哨兵，得到 values。定义 `dp[i][j]` 为保持边界 i、j 不戳破，清空**开区间** `(i,j)` 的最大硬币数。

```text
dp[i][j] = max(dp[i][k] + dp[k][j]
               + values[i]*values[k]*values[j])
           i < k < j
```

计算左右子问题期间 k 作为边界仍然存在；最后才戳破 k。哨兵只表示原数组之外的固定边界，并非每个已戳气球都会变成 1。

### 边界与遍历

`dp[i][i+1]=0`：开区间没有气球。按边界间距 gap 从 2 递增，答案为扩展数组的 `dp[0][n-1]`。

### 正确性

每种清空方案都有唯一的最后一个气球 k。因为 i、k、j 在左右子区间清空时保留，左右子问题的边界不变，可以独立优化。将两侧最优收益与最后一次收益相加，再枚举 k 取最大，即覆盖所有方案。

### 示例

`[3,1,5,8]` 按值依次戳 `1 → 5 → 3 → 8`：

```text
3*1*5 = 15
3*5*8 = 120
1*3*8 = 24
1*8*1 = 8
总计 167
```

### 复杂度

原始数组长度为 n，时间 O(n³)，空间 O(n²)。输入数组不变。

```sh
go test ./dp/interval/l312 -v
```

## 664. 奇怪的打印机

[题目](https://leetcode.com/problems/strange-printer/) · 困难 · [Go 解法](l664/664.go)

### 思路：相同字符共享一次打印

一次操作只能在一个**连续区间**打印同一种字符，可以覆盖之前的内容。不能一次只打印所有不相邻的 a 而跳过中间位置。

相邻相同字符可以合并为一个字符：任意打印方案都能把该位置的打印横向扩展覆盖整段；反过来将整段缩为一点也不会增加操作。因此先压缩连续重复字符，例如 `aaabbbaa → aba`。不能把 `ababab` 压缩为 `ab`。

令压缩后字符串为 chars，`dp[i][j]` 为打印闭区间 `[i,j]` 的最少次数。

```text
先单独打印末尾：dp[i][j] = dp[i][j-1] + 1
对每个 i <= k < j 且 chars[k] == chars[j]：
    dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j-1])
```

第二种选择将打印位置 k 的操作延伸到 j，然后用中间区间的方案覆盖、修复 `(k,j)`，所以 j 不额外增加一次打印。

### 边界与遍历

单字符 `dp[i][i]=1`，空区间费用为 0。实现中 `dp[k+1][j-1]` 在两端相邻时读到下三角的零值。按长度从 2 递增填表，保证所有依赖已经计算。空字符串额外返回 0。

### 正确性

末尾字符既可单独打印，也可与前面的某个相同字符共享操作。共享操作覆盖的中间字符可在之后修复；固定共享位置 k 后，前缀与中间修复分别由子问题最优解完成。上述选择覆盖最优方案中末尾操作的两种情况，因此对区间长度归纳即可得到最优次数。

### 示例

`aba`：先在整个区间打印 `aaa`，再将中间打印为 b，共 2 次。

`abcba`：先打印 `aaaaa`，再将中间三位打印成 b，最后中间一位打印成 c，共 3 次。

`ababab` 需要 4 次，而不是按字符种类计算的 2 次。

### 复杂度

设原长 n、压缩后长 m：时间 O(n+m³)，空间 O(n+m²)（预留 n 个字符容量）；最坏均为 O(n³) 时间、O(n²) 空间。

## 1000. 合并石头的最低成本

[题目](https://leetcode.com/problems/minimum-cost-to-merge-stones/) · 困难 · [Go 解法](l1000/1000.go)

### 可行性：堆数的模约束

每次必须合并连续 k 堆成 1 堆，减少 `k-1` 堆。从 n 堆变为 1 堆必须满足：

```text
(n-1) % (k-1) == 0
```

不满足直接返回 -1。满足时可以不断合并连续 k 堆直到剩 1 堆，因此也是充分条件。题目保证 `k>=2`。

### 从三维状态到二维压缩

自然的定义是 `f[i][j][p]`：把 `[i,j]` 合为 p 堆的最低成本。长度 L 的区间通过尽可能多的合并，最终可降到的最少堆数唯一确定：

```text
r(L) = (L-1) % (k-1) + 1
```

因此本实现只保留 `dp[i][j]`：将 `[i,j]` 合并成 `r(j-i+1)` 堆的最小费用。**不是每个 dp[i][j] 都表示合成一堆。**

### 转移

先枚举分割点 mid，要求左侧 `[i,mid]` 可合成一堆，即 `(mid-i)%(k-1)==0`：

```text
best = min(dp[i][mid] + dp[mid+1][j])
       mid = i, i+(k-1), i+2*(k-1), ... < j
```

分割点步长必须是 `k-1`。左侧为一堆，右侧处于其最少堆数，二者之和通常已是目标 r(L) 堆。

唯一例外是 `r(L)=1`：此时子问题组合先得到 k 堆，需要再合并一次：

```text
若 (L-1)%(k-1)==0：best += sum(stones[i:j+1])
dp[i][j] = best
```

区间和使用前缀和 O(1) 求得。不能对所有区间无条件加区间和，否则会对尚不足 k 堆的局面收取不存在的费用。

### 边界、遍历与正确性

单堆无需操作，`dp[i][i]=0`。按长度从 2 到 n 递增填表。

最优方案在最后一次全区间合并之前，由连续子区间各自合成的 k 堆组成；尚不能合成一堆时，则由 r(L) 个这样的子区间组成。取最左边的一堆作为左子问题，其长度必为 `1 mod (k-1)`，正好对应步长枚举。其余堆由右子问题最优地形成；当可合成一堆时，再付出一次全区间总和。因此没有遗漏最优方案，也没有引入非法合并。

### 示例

`[3,2,4,1], k=2`：合并 3、2，费用 5；合并 4、1，费用 5；合并剩余 5、5，费用 10，总计 20。

同一数组 `k=3` 时，`(4-1)%2 != 0`，不可行。

`[3,5,1,2,6], k=3`：先合并 `[5,1,2]`，费用 8；再合并 `[3,8,6]`，费用 17，总计 25。

### 复杂度

时间 O(n² + n³/(k-1))，通常简写 O(n³/(k-1))（可行且 n>1 时 k<=n）；最坏 O(n³)。空间 O(n²)。

```sh
go test ./dp/interval/l1000 -v
```

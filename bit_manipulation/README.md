## 识别信号与分类

| 需求 | 性质 / 模型 | 代表题 |
| --- | --- | --- |
| 成对抵消只剩一个 | `x^x=0`，异或可交换结合 | 136 只出现一次的数字 |
| 两个单次异常值 | 总异或的一位不同，按该位分组 | 260 只出现一次的数字 III |
| 计数二进制 1 | `x&(x-1)` 清除最低位 1 | 191 位 1 的个数、338 比特位计数 |
| 每个数出现固定次数 | 对各位计数后取模，或有限状态机 | 137 只出现一次的数字 II |
| 小集合状态 | 第 i 位表示元素是否在集合中 | 78 子集；状态压缩 DP |
| 位重排 / 进位 | 固定轮数移动位、异或与进位分离 | 190 颠倒二进制位、371 两整数之和 |

## 模板一：枚举置位与清除最低位

```go
func CountOnes(x uint64) int {
    count := 0
    for x != 0 { x &= x-1; count++ }
    return count
}

// 要求 n<=63；实际枚举仍受指数输出规模限制。
func ForEachSubset(n uint, visit func(uint64)) {
    if n > 63 { panic("too many bits") }
    for mask := uint64(0); mask < uint64(1)<<n; mask++ { visit(mask) }
}
```

CountOnes 时间 O(置位数)、空间 O(1)；固定 64 位时也是有界常数。子集枚举 O(2^n)，如果每个集合展开 n 个元素，则 O(n·2^n)。不要以为能用位表示，就能在 n 很大时枚举全部集合。

常见集合操作（mask 为无符号数，位下标在有效位宽内）：

```text
包含 i：mask & (1<<i) != 0
加入 i：mask | (1<<i)
删除 i：mask &^ (1<<i)
交集 / 并集 / 对称差：a&b / a|b / a^b
枚举非空子掩码：从 sub=mask 开始，反复 sub=(sub-1)&mask，sub=0 时停止
```

如需包含空子掩码，额外处理 0；无符号减法会回绕，写错停止条件可能无限循环。

## 模板二：两个只出现一次的值

```go
// 前提：恰有两个不同值各出现一次，其余值均出现两次。
func TwoSingles(nums []uint64) (uint64, uint64) {
    var different uint64
    for _, x := range nums { different ^= x }
    if different == 0 { panic("invalid input") }
    bit := different & (^different+1)
    var a, b uint64
    for _, x := range nums {
        if x&bit == 0 { a ^= x } else { b ^= x }
    }
    return a, b
}
```

different 是两个异常值的异或，最低置位保证两者进入不同组；相同的成对元素进入同组抵消。时间 O(n)，额外空间 O(1)，返回顺序不固定。这是无符号模板，260 的有符号输入需按相同位宽转换、最后恢复类型，不要混用 int32 与 uint64 的符号扩展假设。

## Go 特别注意

1. int 由平台决定是 32 位还是 64 位；固定数位算法优先用 uint32 / uint64。
2. 有符号右移保留符号信息；需要逻辑右移时先明确转换为无符号类型。
3. 左移不自动保证结果可表示；非恒定位移可能丢失高位，常量溢出则可能编译失败。
4. `^x` 是按位取反，`a ^ b` 是异或，`&^` 为清位；不要与其他语言的乘方记号混淆。
5. 对负数不要不断算术右移直到 0，否则可能永不结束；固定轮数或转无符号处理。
6. 137 的位计数要固定正确位宽；371 的进位迭代应明确有限位宽，而不是忽略整数边界。

练习：136 → 191 → 338 → 260 → 190 → 137 → 78 位掩码 → 状压 DP。

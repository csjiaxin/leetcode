## 一个共同外形，三种不同不变量

```go
func dfs(u int) {
    // 1. 进入：检查终止条件，建立当前状态
    for _, v := range graph[u] {
        // 2. 递归：先判断 v 是否允许进入
        dfs(v)
        // 3. 合并：按题意累计子问题结果
    }
    // 4. 离开：只有当前路径状态需要撤销
}
```

图上可达性通常是 O(V+E)；树上常数次合并为 O(n)；记忆化复杂度是状态数乘转移数；路径枚举和树组合可能是指数规模。不能仅根据“每个函数只写了一个 for”推断为线性。
